# ChatGPT Fan-Out Viewer

[English](README.md)

Tampermonkey-скрипт без залежностей для відображення рядків пошукових запитів, знайдених у доступних браузеру `fetch`-відповідях ChatGPT. Допомагає досліджувати переписування запитів і видиму частину search fan-out.

**Експериментальний неофіційний інструмент.** Це не API OpenAI і не повний журнал серверних пошуків. Лічильник показує кількість унікальних знайдених рядків, а не кількість пошукових викликів. Нуль не означає, що пошуку не було.

## Встановлення

1. Встанови [Tampermonkey](https://www.tampermonkey.net/) для свого настільного браузера.
2. [Відкрий скрипт](https://raw.githubusercontent.com/GendalfW/chatgpt-fan-out-viewer/main/ChatGPT-Fan-Out-Viewer.user.js) та підтвердь встановлення у Tampermonkey.
3. Якщо відкрився звичайний код: скопіюй увесь файл у Tampermonkey → Create a new script, повністю замінивши шаблон. Збережи.
4. Перезавантаж [ChatGPT](https://chatgpt.com/) **до** нового повідомлення. Для перевірки увімкни вебпошук, якщо він доступний.

Посилання встановлення працюватиме після публікації репозиторію за вказаною адресою. Якщо власник, назва або гілка інші, спочатку заміни відповідні посилання й метадані скрипта.

Для оновлення раніше встановленої копії заміни код у наявному скрипті Tampermonkey. Не залишай увімкненими дві копії. Назва та namespace не змінені.

## Панель

- Початкове розташування — праворуч угорі.
- Перетягуй панель за заголовок у межах вікна. Остання перетягнута позиція зберігається локально для відповідного домену.
- `−` згортає панель, `+` розгортає. У згорнутому стані «Копіювати» та «Очистити» приховані.
- «Копіювати» — один запит на рядок у буфері обміну.
- «Очистити» — скидання списку й лічильника. Активний потік може додати нові записи після очищення.

Інтерфейс українською; знайдені запити залишаються мовою оригіналу. Список накопичується протягом життя сторінки, зокрема при переходах усередині застосунку. Очисти його або перезавантаж сторінку для нового вимірювання. Згорнутий стан не запам’ятовується.

## Як це працює

Скрипт обгортає `fetch` сторінки, не змінює параметри запитів і читає копії текстових, JSON та SSE-відповідей. Рекурсивно шукає поля `search_query`, `search_queries`, `searches`, `web_search_queries`, а також `q`/`query` під ключами з `search`, `browse` або `web`. Намагається розібрати й повні вкладені JSON-рядки.

Пробіли на початку й у кінці прибираються; дублікати, порожні рядки та рядки понад 500 символів відкидаються. Знайдений текст показується через `textContent`, а не виконується як код.

## Обмеження

- Серверні пошуки, які не потрапили до браузера, невидимі. WebSocket, XHR і workers не перехоплюються; раніше збережене сторінкою посилання на `fetch` може обійти обгортку.
- Внутрішні поля й транспорт ChatGPT можуть змінитися. Непідтримуваний формат або фрагментований вкладений JSON можуть спричинити пропуски.
- Визначення евристичне: подібні поля в іншому payload або прикладах у чаті можуть давати хибні спрацювання. Це не підтверджений журнал виконання інструментів.
- Повторений пошуковий рядок рахується один раз. Лічильник не вимірює всі fan-out операції, витрати API чи чинники ранжування.
- Скрипт не запитує історію спеціально. Старі дані можуть з’явитися, якщо ChatGPT сам завантажить відповідний payload після запуску; повнота історії не гарантується.
- Читання копій відповідей створює додаткове локальне навантаження на пам’ять і процесор.
- Цільове середовище — настільний Tampermonkey на `chatgpt.com` та старому `chat.openai.com`. Обмеження браузера або інші перехоплювачі можуть завадити роботі. Підтвердженої матриці сумісності браузерів немає.

## Приватність

Немає API-ключа, аналітики, телеметрії, зовнішніх runtime-залежностей чи відправлення знайдених запитів. Вони зберігаються в пам’яті сторінки, доки ти їх не скопіюєш. Позиція панелі — у `localStorage` сайту, не в захищеному сховищі. Деталі: [PRIVACY.md](PRIVACY.md).

Метадані GitHub-версії містять `@updateURL` і `@downloadURL`: Tampermonkey може звертатися до GitHub для перевірки й завантаження оновлень згідно зі своїми налаштуваннями. Знайдені запити при цьому не передаються.

## Якщо не працює

| Симптом | Що перевірити |
| --- | --- |
| Немає панелі | Скрипт увімкнений, Tampermonkey має доступ до ChatGPT; після встановлення сторінку перезавантажено. |
| Панель є, список порожній | Виконай новий запит із вебпошуком. Формат може бути непідтримуваним або запити взагалі не передаватися браузеру. |
| Зайві записи | Можливе евристичне збігання полів у сторонніх payload або прикладах. |
| Дублікати або конфлікти | Вимкни старі копії та інші скрипти-перехоплювачі й перезавантаж сторінку. |
| Потрібно скинути позицію | На ChatGPT виконай у консолі `localStorage.removeItem('cgpt-fanout-position')` і перезавантаж сторінку. Видалиться тільки збережена позиція. |

У bug report вкажи версію браузера, Tampermonkey, скрипта та нешкідливий приклад для відтворення. Не публікуй приватні чати, повні HAR-файли, токени чи конфіденційні запити.

## Перевірки

Якщо є Node.js, з кореня репозиторію виконай:

```sh
node --check ChatGPT-Fan-Out-Viewer.user.js
node tests/smoke.test.cjs
```

Це синтетичні перевірки парсера, дедуплікації, потокових UTF-8 фрагментів, координат і збереження перетягнутої позиції. Вони не підтверджують живу сумісність із поточною версією ChatGPT або зовнішній вигляд. Перед релізом вручну перевір встановлення, новий пошук, копіювання, очищення, згортання, перетягування, зміну розміру вікна та відновлення позиції.

Збирання, npm, сервер і GitHub Pages не потрібні.
